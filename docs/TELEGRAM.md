# Telegram бот барои муштариён — дастури насб

Муштарӣ ботро як бор мекушояд, **Start**-ро пахш мекунад ва тугмаи **«📱 Рақами телефонро фиристодан»**-ро мезанад. Бот ӯро аз рӯи телефоне, ки дар бор навишта шудааст, мешиносад (9 рақами охир). Баъд худкор паём меояд:

- 📦 **Бор дар Душанбе расид**: вақте ки бор сабт мешавад ё ба анбор гузошта мешавад (ё партия «Расид» мешавад). Дар паём рақам, ҷой, вазн, ҳаҷм, маблағ ва қарз ҳаст.
- ✅ **Пардохт қабул шуд**: маблағ ва қарзи боқимонда.
- 🤝 **Бор супорида шуд.**
- 💰 **Қарзи ман**: муштарӣ дар бот тугмаро пахш мекунад ва борҳо ва қарзашро мебинад.

Калиди бот танҳо дар Supabase нигоҳ дошта мешавад. Сайт ва браузер онро намебинанд.

## Насб (як бор, тақрибан 15 дақиқа)

### 1. Сохтани бот
Telegram → **@BotFather** → `/newbot` → номро нависед (масалан `HOJI-NAIM CARGO`) → username-ро нависед (бояд бо `bot` тамом шавад, масалан `hoji_naim_cargo_bot`).
BotFather **токен** медиҳад (масалан `123456:ABC...`). Онро нигоҳ доред ва ба касе нафиристед.

### 2. Функсия дар Supabase
Supabase → лоиҳа → **Edge Functions** → **Deploy a new function** → **Via Editor**.
- Ном: `telegram-bot`
- Матни файли `supabase/functions/telegram-bot/index.ts`-ро аз GitHub нусха карда, ба редактор гузоред → **Deploy**.
- Баъд дар саҳифаи функсия → **Settings / Details** → **Verify JWT** (Enforce JWT verification)-ро **хомӯш** кунед → Save. Бе ин Telegram ба функсия расида наметавонад. Функсия ҳар даъватро худаш бо калидҳо месанҷад.

### 3. Калидҳо (Secrets)
Supabase → **Edge Functions** → **Secrets** → **Add new secret**:

| Ном | Қимат |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен аз қадами 1 |
| `TELEGRAM_WEBHOOK_SECRET` | калиди тасодуфӣ (дар Админ-панел → «Калиди тасодуфӣ») |
| `HOOK_SECRET` | калиди тасодуфии дигар |

### 4. SQL
Supabase → **SQL Editor** → матни `supabase/telegram.sql`-ро гузоред.
Дар он `ИВАЗ_КУНЕД_HOOK_SECRET`-ро бо ҳамон `HOOK_SECRET` иваз кунед → **Run** → «Success».

### 5. Пайвасти бот ба функсия
Дар браузер ин суроғаро кушоед (`<ТОКЕН>` ва `<TELEGRAM_WEBHOOK_SECRET>`-ро бо қиматҳои худ иваз кунед):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://wfxbgkasstkxzmyrjwpi.supabase.co/functions/v1/telegram-bot&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

Бояд `{"ok":true,"result":true,"description":"Webhook was set"}` барояд.

### 6. Санҷиш
1. Сайт → Админ-панел → «Telegram бот» → **Санҷиши бот**. Бояд «Бот кор мекунад: @...» барояд.
2. Ботро дар телефон кушоед → Start → рақамро фиристед → «Шумо обуна шудед ✅».
3. Дар сайт бори озмоиширо бо ҳамон телефон сабт кунед → паём бояд дар 1–5 сония биёяд.
4. Дар Админ-панел дар ҷадвали паёмҳо «Фиристода шуд» пайдо мешавад.

## Пайванд барои муштариён
`https://t.me/<username>`: онро дар WhatsApp, Instagram ё дар чек нависед. Дар Админ-панел тугмаи «Нусха» ҳаст.

## Агар паём наояд
- Админ-панел → ҷадвали паёмҳо: агар «Хато» бошад, курсорро болои он баред, ва сабаб нишон дода мешавад.
- Муштарӣ бояд ҳамон рақамеро фиристад, ки дар бор навишта шудааст. 9 рақами охир муқоиса мешаванд.
- Агар муштарӣ ботро блок кунад, ӯ ғайрифаъол мешавад. Бори дигар Start пахш кунад, боз фаъол мешавад.
- Хабари Telegram ҳеҷ гоҳ сабти бор ё пардохтро бозмедорад: агар бот кор накунад, маълумот ба ҳар ҳол сабт мешавад.
